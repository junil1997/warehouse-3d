# 창고 3D 배치 · 재고 정리

울산과학대 창고를 3D로 보면서 가구·물품을 넣고 빼고 옮겨 보는 웹 도구입니다.
설치 없이 브라우저에서 돌아가고, 배치 데이터(`data/layout.js`)를 git으로 버전 관리합니다.

## 실행

- **그냥 열기**: `index.html` 더블클릭 (인터넷 연결 필요 — 3D 엔진 Three.js를 CDN에서 받음)
- **로컬 서버**(권장): 이 폴더에서 `python -m http.server 8765` → http://localhost:8765
- **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / root 로 켜면 휴대폰에서도 열림

## 조작

| 동작 | 방법 |
|---|---|
| 회전 / 화면 이동 / 확대 | 왼쪽 드래그 / 오른쪽 드래그 / 휠 |
| 물품 이동 | 물품을 끌기 (5cm 단위, Shift 누르면 1cm) |
| 회전 · 미세이동 · 빼기 | `R` 90° · 방향키 5cm · `Del` |
| 되돌리기 | `Ctrl+Z` |
| 평면도 | 상단 [평면도] 버튼 |
| 정리 상태 색 보기 | 상단 [상태별 색] (미정·유지·이동·폐기) |

오른쪽 패널
- **물품 목록**: 구역별 리스트, 체크 해제 = 창고에서 빼기, 겹침·벽밖 ⚠ 표시
- **선택 물품**: 이름·치수(cm)·위치·회전·정리 상태·메모 편집, 복제·삭제
- **공간 치수**: 바닥 꼭짓점, 천장 높이, 창문 벽, 문 위치 — 실측값을 여기에 입력
- **저장·버전**: 배치안 스냅샷(A안/B안), layout.js·CSV·JSON 내보내기/불러오기

## 버전 관리 흐름

1. 앱에서 수정 (브라우저에 자동 저장됨)
2. [저장·버전] → 버전 번호 올리고 **layout.js 내보내기**
3. 받은 파일로 `data/layout.js` 교체
4. 커밋

```bash
git add data/layout.js
git commit -m "v0.2.0 실측 치수 반영"
```

변경 이력은 `git log -p data/layout.js` 로 볼 수 있고, 물품 하나가 한 줄이라 무엇이 바뀌었는지 diff로 바로 보입니다.

## 좌표 기준 (단위 cm)

- X: 입구 유리문 쪽 벽(0) → 안쪽 창고 방향
- Z: 창문 벽(0) → 핑크 벽 방향
- 물품 `x,z` = 바닥면 중심, `y` = 바닥에서 띄운 높이(캐비닛 위에 얹은 물건 등)
- `rot` = 회전 각도(°)
