# 창고 3D 배치 · 재고 정리

울산과학대 창고를 3D로 보면서 가구·물품을 넣고 빼고 옮겨 보는 웹 도구입니다.
설치 없이 브라우저에서 돌아가고, 배치 데이터(`data/layout.js`)를 git으로 버전 관리합니다.

## 실행

- **그냥 열기**: `index.html` 더블클릭 (인터넷 연결 필요 — 3D 엔진 Three.js를 CDN에서 받음)
- **로컬 서버**(권장): 이 폴더에서 `python -m http.server 8765` → http://localhost:8765
- **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / root 로 켜면 휴대폰에서도 열림

## 공유 저장소 설치 (여러 사람이 같이 저장 — 처음 한 번만)

배치 데이터는 구글 시트에 저장됩니다. 화면 오른쪽 위 **[☁ 저장]**을 누를 때마다 시트에 버전이 한 줄씩 쌓여서
누가·언제·무엇을 바꿨는지 남고, [저장·버전] 탭 → **저장 이력 보기**에서 예전 버전을 불러올 수 있어요.

1. 구글 드라이브에서 **새 구글 시트** 만들기 (이름 예: `창고배치_공유저장소`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣기 → 저장(💾)
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인(내 구글 계정) → **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)
5. [`data/config.js`](data/config.js) 의 `WAREHOUSE_API = ''` 따옴표 안에 그 URL 붙여넣기 → 커밋·푸시
6. (선택) 아무나 저장하지 못하게 하려면: Apps Script **프로젝트 설정 → 스크립트 속성**에 `PASSCODE` = 원하는 암호.
   동료들은 처음 저장할 때 암호를 한 번 입력하면 됩니다. 보기는 링크 아는 누구나 가능.

시트에는 `versions`(전체 이력), `물품목록`, `벽실측` 탭이 자동으로 생깁니다. 물품목록·벽실측 탭은 **보기용**이라
시트에서 고쳐도 앱에 반영되지 않아요 — 수정은 앱에서 하고 [☁ 저장].

Code.gs 를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 해야 반영됩니다 (URL은 그대로).

### 같이 쓸 때 규칙

- 고친 뒤 **[☁ 저장]**을 눌러야 다른 사람에게 보여요. 안 누르면 "● 저장 안 된 변경 있음" 표시.
- 다른 사람이 저장하면 45초 안에 자동으로 새 배치로 바뀝니다(내가 고치던 게 없을 때).
- 둘이 동시에 고치면 나중에 저장한 사람에게 "새 버전 있음"이 뜨고, **새 버전 불러오기** 또는 **덮어쓰기**를 고릅니다.
  덮어써도 상대 버전은 이력에 남아 있어요.

## 조작

| 동작 | 방법 |
|---|---|
| 회전 / 화면 이동 / 확대 | 왼쪽 드래그 / 오른쪽 드래그 / 휠 |
| 물품 이동 | 물품을 끌기 (5cm 단위, Shift 누르면 1cm) |
| 회전 · 미세이동 · 빼기 | `R` 90° · 방향키 5cm · `Del` |
| 되돌리기 | `Ctrl+Z` |
| 평면도 | 상단 [평면도] 버튼 |
| 정리 상태 색 보기 | 상단 [상태별 색] (미정·유지·이동·폐기) |

오른쪽 패널
- **물품 목록**: 구역별 리스트, 체크 해제 = 창고에서 빼기, 겹침·벽밖 ⚠ 표시
- **선택 물품**: 이름·치수(cm)·위치·회전·정리 상태·메모 편집, 복제·삭제
- **공간 치수**: 바닥 꼭짓점, 천장 높이, 창문 벽, 문 위치 — 실측값을 여기에 입력
- **저장·버전**: 배치안 스냅샷(A안/B안), layout.js·CSV·JSON 내보내기/불러오기

## 버전 관리 흐름

1. 앱에서 수정 → [☁ 저장] (공유 저장소에 버전으로 쌓임)
2. [저장·버전] → 버전 번호 올리고 **layout.js 내보내기**
3. 받은 파일로 `data/layout.js` 교체
4. 커밋

```bash
git add data/layout.js
git commit -m "v0.2.0 실측 치수 반영"
```

변경 이력은 `git log -p data/layout.js` 로 볼 수 있고, 물품 하나가 한 줄이라 무엇이 바뀌었는지 diff로 바로 보입니다.

## 실측 입력 (공간 치수 탭)

방은 모서리 **A**(입구 유리칸막이와 긴 핑크벽이 만나는 곳)에서 출발해 한 바퀴 도는 벽 13개로 되어 있습니다.
3D 바닥의 빨간 동그라미 A~M이 모서리 이름이에요.

| 칸 | 넣는 값 |
|---|---|
| 실측 (초록) | 줄자로 잰 벽 길이. 비워 두면 추정값 사용 |
| 끝 각° | 벽이 끝나는 모서리의 방 안쪽 각도 — 직각 90, 기둥처럼 튀어나온 모서리 270 |
| 휨 | 곡면 벽 양 끝을 실로 이었을 때 가운데에서 벽까지 거리 |

다 넣고 나서 "어긋남"이 크면(5cm 이상) 어느 길이나 각도가 틀린 것입니다.
현장에서 적을 표는 [실측 기입표 CSV] 버튼으로 받을 수 있어요.

## 좌표 기준 (단위 cm)

- X: 입구 쪽(0) → 안쪽 창고 방향, Z: 창문 쪽(0) → 핑크 벽 방향
- 물품 `x,z` = 바닥면 중심, `y` = 바닥에서 띄운 높이(캐비닛 위에 얹은 물건 등)
- `rot` = 회전 각도(°)
